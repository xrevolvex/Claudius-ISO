Python on Claudius
==================

Run a script:
  * Double-click a .py file: it opens in Thonny, a friendly Python editor (press F5 to run)
  * Right-click it > Run with Python: runs it in a terminal
  * In a terminal:  python3 hello.py

Install packages:
  * For one project (recommended):  python3 -m venv .venv && .venv/bin/pip install requests
  * Command-line apps:               pipx install httpie
  * From Debian:                     claudius install python3-pandas

Also installed: IDLE, IPython (ipython3), Geany, tkinter, numpy, requests.
Right-click inside any folder > "New Python project here" sets up a project with its own venv.

Try the examples in this folder!
